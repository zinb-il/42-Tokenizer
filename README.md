**Pourquoi BNB Smart Chain plutôt qu'Ethereum ?**
Le sujet est un partenariat avec BNB Chain, et BSC est compatible EVM, ce qui signifie que tu peux utiliser Solidity et les mêmes outils qu'Ethereum (Remix, OpenZeppelin) tout en déployant sur le testnet BSC . C'est le choix le plus cohérent avec l'énoncé

**Pourquoi utiliser Solidity pour créer un smart contract ?**
On utilise **Solidity** pour créer des smart contracts parce que c'est un langage conçu pour programmer des contrats intelligents sur la blockchain Ethereum et sur d'autres blockchains compatibles avec l'Ethereum Virtual Machine (EVM), comme BNB Smart Chain.
